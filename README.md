# De la ESP32 a la IA

Material de prácticas de **Robótica y Fabricación Digital II** (2.º de Bachillerato, IES Murillo, Sevilla): repaso de la placa **ESP32 STEAMakers** (sensores y actuadores digitales y analógicos, salidas y PWM, I2C y sensores especiales), la placa como servidor web, comunicación entre placas con ESP-NOW y paneles IoT, y, para terminar, prácticas con la **ESP32 STEAMakers AI** (ESP32-S3) y agentes de inteligencia artificial.

Web: https://profetonino.github.io/esp32-ia-ryfd2/

## Estructura

```
index.html          portada
seguridad.html      normas de seguridad eléctrica
n0.html … n4.html   niveles (N0, N1, N1b, N2, N2b, N3, N4) y pi.html (paneles IoT)
assets/             estilos.css y app.js (comunes a todas las páginas)
img/                imágenes
```

Todo es HTML, CSS y JavaScript sin dependencias externas.
